# Лаборатория композитов

Streamlit-приложение для ПТФЭ с двумя наполнителями. Прогноз пяти свойств,
подбор концентрации и режима под целевые свойства, графики с экспериментальными
точками и модельными интервалами, сравнение составов и экспорт CSV.

| Наполнитель | Диапазон | Режимы |
| --- | --- | --- |
| УНТ | 1–5% | Статическое; УЗ+100; статическое с ультразвуковой ванной |
| Углеродное волокно | 10–30% | Статическое; УЗ+100; статическое с активированным волокном |

УВ в названии старого режима УНТ означает ультразвуковую ванну, а УВ как
наполнитель означает углеродное волокно. В интерфейсе используются полные названия.
Активированное волокно является отдельным режимом на листе лабораторной таблицы.

## Запуск

Проверено на Python 3.12.1. В новом окружении:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

Для фонового локального запуска на Windows:

```powershell
.\run_local.ps1
# Или явный выбор интерпретатора:
.\run_local.ps1 -Python 'C:\path\to\python.exe' -Port 8501
```

Скрипт выбирает свободный порт начиная с 8501, запускает сервер скрыто,
проверяет health endpoint и выводит адрес. Приоритет интерпретаторов:
параметр `-Python`, локальная `.venv`, существующее окружение
`Desktop/huggface_material/mtl1/.venv`, затем Python из PATH.
PID и логи находятся в `.runtime/`. Сервер привязан к 127.0.0.1.
Скрипты загрузки моделей используют пути относительно исходников, а не текущей папки.

## Данные и модели

Исходный GitHub: https://github.com/MarkSabenin/MaterialStreamlitApp,
база изменений `b96af4289f3e199b6704c862384673cf11efc432`.
Изучены ветки MARK, IVAN, dev и KOLYA локального репозитория mtl1 после fetch.
Для текущей реализации использованы схема обработки повторов и GPR из ноутбуков
MARK/IVAN, а также API опубликованного приложения.

УНТ: сохранены исходные `raw_data_van.xlsx` и веса `model_package/`.
Используются исходные два sklearn-регрессора для прочности/удлинения и
GPflow для модуля/трения/износа. Дополнительная концентрация УНТ 1,5% из новой
таблицы не меняет исторические модели. Чистый ПТФЭ также не добавлен к ним.
Контрольные 21 прогноз сохранены в `baseline_cnt.json` до правки кода и проверяются тестом.

Волокно: `data/fiber_experiments.csv` содержит 135 индивидуальных измерений
с листа «ПТФЭ+УВ (3 режима)»: пять концентраций, три режима, девять повторов.
`data/fiber_source.json` фиксирует исходный файл, SHA-256 и замечания к единицам.
Парсер находит блоки по заголовкам, корректно переставляет трение/износ,
обрабатывает объединённые ячейки, исключает строки средних и проверяет полноту.
В исходном заголовке удлинения стоят МПа; для этого показателя в приложении
приняты проценты. Исходные числа сохранены без изменений.

Для обновления данных и воспроизводимого обучения:

```powershell
python import_experiments.py 'C:\path\to\laboratory.xlsx'
python train_fiber.py
```

Веб-приложение загружает готовый пакет, не запускает обучение при действиях
пользователя. Проверка SHA-256 блокирует загрузку устаревшей модели после изменения CSV.

Базовое сравнение: независимые GPR с Matérn 5/2 и RBF (с линейным компонентом) и
совместный GPflow Matérn 5/2 × Coregion. Первоначальный выбор по MAE для каждого свойства.
Четыре свойства волокна используют независимые GPR; трение уточнено отдельно.
Подробные результаты базового сравнения:
[reports/fiber_validation.md](reports/fiber_validation.md).
Кросс-валидация исключает целые концентрации 15%, 20%, 25% со всеми режимами;
10% и 30% всегда остаются в обучении. Скейлеры обучаются внутри фолдов.
Эти фолды использованы и для выбора моделей; для независимой проверки нужны
дополнительные эксперименты.

Для трения УВ проверены 144 конфигурации с исходной концентрацией, log(c+0.1),
1/c², sin(c), полиномами, взаимодействиями режима и концентрации, а также
ограничениями гладкости GPR. Выбран Ridge(alpha=0.01) с двумя индикаторами
режима и их взаимодействиями с концентрацией. На прежних трёх фолдах
R² = 0.365397, MAE = 0.013083, MAPE = 3.780%, против R² = -0.058493 у
предыдущего GPR. Кривые трения теперь линейные внутри каждого режима,
без локального притягивания к экспериментальным точкам.

Перебор и подробная проверка: [reports/friction_validation.md](reports/friction_validation.md).
Эти оценки использованы для подбора модели и не являются независимым тестом.
Воспроизведение поиска: `python tune_friction.py`; обновление только трения:
`python refine_friction.py`. Полное обучение через `train_fiber.py` также
применяет выбранное уточнение. После переобучения перезапустите Streamlit,
чтобы сбросить кеш моделей и старые результаты в сеансе.

## Существенные исправления

- Наполнитель, диапазон, режимы, результаты, цели и графики разделены по материалам.
- Поиск состава проверяет сетку, локальные минимумы и точные границы диапазона.
- Нулевая цель не вызывает деления на ноль; отрицательные цели и нулевые веса проверяются.
- Удаление выбранных составов сохраняется при последующих действиях и переключениях.
- CSV включает наполнитель и режим; технические ID не экспортируются.
- Для логарифмированных свойств показаны асимметричные интервалы в физических единицах,
  а не величина σ в лог-шкале рядом со значением в МПа или мг/ч.
- Убраны установка пакетов из приложения и перезапись функции TensorFlow булевым значением.
- Версии зависимостей закреплены, включая scikit-learn 1.8.0 для старых сохранённых моделей.
- Графики рассчитываются пакетно и кешируются по наполнителю и свойству.

Центральный прогноз для log1p-выходов сохранён как expm1(μ), то есть медиана
обратного распределения. Интервалы являются модельными, а не гарантией покрытия
разброса новых образцов. У старой модели УНТ сохранён исходный predict_y,
у GPR волокна интервалы относятся к скрытой функции (predict_f/return_std).
Для трения используется приближённая ковариация коэффициентов Ridge с остаточной
дисперсией и эффективным числом степеней свободы; интервал относится к среднему тренду.
Меньшая скорость износа в мг/ч означает лучшую износостойкость.

## Проверка

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют импорт Excel с объединёнными ячейками, порядок свойств,
пропуски, старые прогнозы УНТ, конечность результатов на сетке, интервалы,
запрет экстраполяции, обратный поиск на границах и внутри диапазона,
загрузку из другой папки и Streamlit-сценарии переключения, графиков,
нулевой цели, сравнения и удаления.
